# Lessop

**A Windows application for managing lesson schedules and automating access to online classes.**

Lessop helps students organize their school timetable, keep meeting links in one place, and reduce the time spent manually joining online lessons.

## Features

- Automatic opening of online meeting links according to the lesson schedule.
- Weekly lesson timetable and digital diary.
- Management of lesson names, start times, and meeting links.
- Lesson reminders and configurable sound notifications.
- Local storage of schedules and application settings.
- Localization support.

## Getting Started

To run the project from source, you will need:

- A Windows PC.
- .NET 10 SDK and the .NET MAUI Windows workload.
- An IDE with .NET MAUI support, such as Visual Studio.

Clone or download the repository, open the solution or project file in your IDE, restore the dependencies, and select the Windows target to build and run the application.

## About the Project

Lessop was created to solve a practical problem: making online learning more convenient by automating routine tasks and bringing lesson schedules, meeting links, and reminders together in one application.

The project demonstrates experience with desktop application development, asynchronous programming, user interface design, and local data management.
